# Cambios

## 1.1.3

- Una descarga de instalación identificada como `StayHere-1.1.3.zip`, con `manifest.json` en su raíz.
- Instrucciones de instalación directas y diferenciadas de las descargas de código fuente.
- Verificación de los archivos del ZIP generado y comprobación de navegador sobre la copia extraída del paquete.

## 1.1.2

- Código de la extensión agrupado en `extension/`.
- Imágenes, pruebas documentadas y materiales de publicación reunidos en `docs/`.
- README centrado en instalación y uso, con una guía separada para desarrollo.
- Rutas de pruebas, validación y empaquetado adaptadas a la nueva estructura.

## 1.1.1

- Botón de apoyo conectado a la página pública de Ko-fi de laloerraz.
- Sponsor de GitHub configurado con el mismo creador.
- Exclusiones y comprobación preventiva para evitar subir credenciales o datos locales.
- El pago se realiza fuera de la extensión, sin widgets ni nuevas autorizaciones.

## 1.1.0

- Nueva marca Stay Here e icono de mano abierta sobre un círculo celeste.
- Protección de scripts instalada con opciones privadas por documento, sin aceptar mensajes públicos para desactivarla.
- Botón para recargar la página al cambiar opciones.
- Integración de apoyo por Ko-fi preparada y oculta hasta configurar una URL válida.
- Política de privacidad, ficha de Chrome Web Store y paquete de distribución reproducible.
- Pruebas de regresión e instalación en un perfil de navegador independiente.
